# Academic & Coursework Tracking Dashboard

A static web dashboard for tracking course grades, credit hours, and cumulative GPA, built as part of the Mini-Project Git Workflow Challenge (ICS 4D, Strathmore University).

## Features

- Add courses with course code, credit hours, and letter grade
- Automatic weighted GPA calculation
- Total credits summary
- Course data persisted locally via `localStorage`
- Grade distribution bar chart (Chart.js)
- Responsive layout for mobile and desktop

## Tech Stack

- HTML5, CSS3, vanilla JavaScript
- [Chart.js](https://www.chartjs.org/) (via CDN)
- Browser `localStorage` for persistence
- Deployed via GitHub Pages
